# TecnoShop — Tienda online

## Descripción

TecnoShop es una aplicación web que simula una tienda online de productos tecnológicos. Permite explorar un catálogo, consultar precios y stock, agregar productos al carrito, modificar cantidades y realizar una compra.

## Funcionalidades

- Catálogo de productos con buscador.
- Carrito de compras con cálculo automático del total.
- Control de stock disponible.
- Guardado del carrito para conservarlo al recargar la página.
- Confirmación de compra.

## Tecnologías utilizadas

HTML5, CSS3, JavaScript y SweetAlert2.
